# Ramen Bowl

A single steaming bowl of ramen, drawn entirely in code with the Python standard library.
The noodle is the hero: a glossy broth, noodles lifted high by chopsticks, a halved soft-boiled egg, chashu, green onion and nori, with steam rising over a dark, warm background.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024×1024). The program uses only the Python standard library, needs no network access, and is fully deterministic — running it twice produces a byte-identical image.
